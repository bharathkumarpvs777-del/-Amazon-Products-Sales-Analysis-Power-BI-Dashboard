# 📊 Amazon Products Sales Analysis – Power BI

## 📌 Project Overview

The **Amazon Products Sales Analysis** project is an interactive business intelligence dashboard developed using Microsoft Power BI. The objective is to analyze Amazon sales performance, identify top-performing products, evaluate product categories, and understand sales trends through data visualization.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track Year-to-Date (YTD) and Quarter-to-Date (QTD) sales.
- Identify top-performing products.
- Analyze customer reviews.
- Understand monthly and weekly sales trends.
- Compare sales across product categories.

## 📈 Dashboard Features

**1. Key Performance Indicators (KPIs)**
- YTD Sales
- QTD Sales
- YTD Products Sold
- YTD Customer Reviews

**2. Sales Trend Analysis**
- Monthly sales analysis using an area chart.
- Weekly sales analysis using a column chart.

**3. Product Category Analysis**
- Category-wise sales performance.
- Comparison of YTD and QTD sales.

**4. Top 5 Products Analysis**
- Top 5 products based on YTD sales.
- Top 5 products based on YTD customer reviews.

**5. Interactive Filters**
- Product Category
- Quarter (Qtr)

This dashboard helps stakeholders monitor sales performance, identify popular products, evaluate category-level performance, understand customer engagement, and make data-driven business decisions.

## 🚀 How to Run

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `Sales Analysis.pbix` file.
4. Explore the dashboard using interactive filters.
